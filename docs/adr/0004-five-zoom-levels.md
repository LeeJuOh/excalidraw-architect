# 줌 레벨은 C4 셋이 아니라 다섯이다

C4의 Context·Container·Component·Code를 그대로 쓰지 않고, 시스템 컨텍스트(L1) / 배포 단위(L2) / 모듈 경계(L3) / 레이어(L4) / 경계 타입(L5) 다섯 단계로 고정한다. Gradle 멀티모듈이나 NestJS 모듈은 C4에 칸이 없는데, 백엔드 실무에서 가장 자주 그리는 단위라 L3로 끼워 넣었다. 레벨은 스택과 무관하고, 각 레벨에 허용되는 디테일(L2 엔드포인트·토픽명, L3 모듈명·소유 테이블명, L4부터 클래스)을 고정한다. 도면 파일명이 줌 경로가 되므로 레벨을 나중에 바꾸면 저장된 도면 전부가 어긋난다.

## Considered Options

- C4 넷 그대로: 모듈 층이 없어 Component에 모듈과 클래스가 섞였다.
- 레벨을 스택마다 다르게: 스택이 바뀌면 그림 읽는 법이 달라져 기각했다.
- DDD 전용 레벨 추가: 바운디드 컨텍스트는 L2 또는 L3 박스 그 자체이므로 레벨 추가 없이 라벨로 표현한다.
