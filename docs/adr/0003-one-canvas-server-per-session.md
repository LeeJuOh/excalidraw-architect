# 에이전트 세션 하나에 캔버스 서버 하나, 브라우저 탭 하나

업스트림은 머신당 캔버스 서버 하나(포트 3000)라서, 동시에 작업하는 에이전트 세션들이 캔버스 하나를 나눠 쓴다. 우리는 `session start`가 빈 포트에 서버를 따로 띄우고 세션 키를 발급하게 한다. 이후 호출에는 `--session <키>`를 붙인다. 키를 생략하면 살아 있는 세션이 하나일 때는 그 세션으로, 여럿이면 에러다 — 컴팩션으로 키를 잃었을 때 `session list`가 하나면 자동 복귀하고 여럿이면 묻는 규칙과 같다(2026-09-19 2차 검수 A6). 키는 서버가 발급하며 호스트의 세션 ID나 PPID에 의존하지 않으므로, Claude와 Codex에서 똑같이 동작한다. 캔버스 세션을 끝내는 방법은 사용자의 `session end` 하나뿐이고 자동 감지는 없다.

세션은 시작 시점에 프로젝트 루트(cwd에서 위로 올라가 찾은 git 루트, 없으면 cwd, `--project`로 덮어쓰기 가능)를 고정해 가진다. 이후 호출은 세션 키만으로 같은 프로젝트를 가리키므로, 하위 폴더나 스킬 폴더에서 불러도 근거 경로와 프로젝트별 스냅샷 저장소가 어긋나지 않는다. 산출물 export 경로는 사용자가 지정하거나 에이전트가 선택하며, 프로젝트 루트 고정이 산출물 저장 폴더를 제한하지는 않는다(2026-09-16 명확화). (2026-09-14 추가, 검수 R03)

## Considered Options

- 프로젝트 경로별 포트: 같은 폴더에서 연 여러 세션을 나눌 수 없어 기각했다.
- 서버 하나에 세션별 frame: 캔버스를 분리하고 싶을 때 코드가 두 벌 필요해 기각했다.
- MCP 기본: 키가 필요 없지만 [ADR-0002](0002-cli-first-via-skill-shim.md)를 뒤집어야 한다. 도그푸딩에서 키를 매번 붙이는 게 번거로우면 다시 검토한다.
