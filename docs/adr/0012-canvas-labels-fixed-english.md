# 캔버스에 보이는 고정 라벨은 대화 언어와 무관하게 영어로 고정한다

선 표기의 보이는 라벨 5종 — 동기 호출 `[sync]`, 비동기 이벤트 `[async]`, 응답 `response:`, 추론 `inferred`, 근거 검사 실패 `no evidence:` — 은 대화 언어가 무엇이든 영어 문자열로 고정한다(2026-09-22 결정). 라벨은 그림마다 같아야 하고 저장된 `.excalidraw` 파일끼리 맞아야 하며, 07의 서버가 `no evidence:` 텍스트를 직접 생성하므로 문자열이 한 벌로 정해져 있어야 한다. 초안은 5종 중 3종만 영어를 박고 2종은 "사용자 언어로"라고 두었는데, 코드 리뷰에서 그 모순이 잡혔고 같은 개념에 매번 다른 토큰이 나왔다. 라벨 뒤에 채우는 이름(호출명·이벤트명·결과)은 코드에서 오므로 고정 대상이 아니다. 문자열의 원본은 [ADR-0006](0006-canvas-guide-single-source-via-mcp.md)대로 `docs/canvas-guide.md` 한 벌이며, PRD·이슈·용어 사전·다른 ADR은 값을 복사하지 않고 그 파일을 가리킨다.

## Considered Options

- PRD §3 초안대로 한국어 고정(`[동기]`·`[비동기]`·`응답:`·`추론`·`근거 없음:`): 영어로 대화하는 사용자에게 같은 문제가 뒤집혀 생기고, 코드에서 온 영어 이름과 한 라벨 안에서 섞여 기각했다.
- 대화 언어를 따라가기: 그림마다 라벨이 달라지고, 저장된 파일끼리 맞지 않으며, 서버가 생성하는 텍스트가 세션 언어를 알아야 해 기각했다.
- 의미만 정하고 문자열은 에이전트 재량: 초안이 이것이었다. 매번 다른 토큰이 나와 범례와 그림이 어긋났고, 서버 생성 텍스트와 에이전트 라벨이 같은 개념을 다르게 적어 기각했다.

## Consequences

- 07의 서버가 생성하는 근거 검사 실패 텍스트도 영어 문자열이다.
- 한국어 문서에서 개념명(근거 없음·추론·동기·비동기)은 한국어로 쓰되, 캔버스에 보이는 문자열을 인용하지 않는다. 문자열이 필요한 자리는 `docs/canvas-guide.md`를 가리킨다.
- [ADR-0005](0005-server-checks-evidence-and-demotes.md)가 구체 표기의 자리로 PRD §3을 가리키던 것은 `docs/canvas-guide.md`로 바뀐다.
- 캔버스에 영어 라벨이 보인다. 한국어 사용자가 이를 낯설어하는지는 02 도그푸딩에서 본다.
