# 04: 세션별 캔버스 — MCP 프로세스당 캔버스 하나, CLI `session start/end/list`·`--session`

> 02 도그푸딩(구현 뒤)의 판정이 수정 사항으로 돌아온다.

**What to build:** 에이전트 세션 둘을 같은 폴더에서 동시에 열면 각자 자기 캔버스 서버와 브라우저 탭을 가진다. **MCP 경로(주)**: 에이전트가 `session_start` 툴에 프로젝트 경로를 넘기면 호스트가 띄운 MCP 프로세스가 캔버스 세션을 새로 띄워 붙고 사용자에게 URL과 프로젝트 루트를 알린다. 서버는 받은 경로에서 위로 올라가 git 루트를 찾는다(없으면 받은 경로). 그리는 툴은 키도 경로도 받지 않고, 붙기 전에 부르면 `session_start`를 안내하는 에러를 낸다. 붙은 세션은 프로세스 수명 동안 고정이다. 같은 프로젝트에 살아 있는 캔버스 세션이 이미 있으면 새로 띄우기 전에 그 목록(키·URL)을 한 줄 알리되 묻지 않고, 사용자가 말하면 `session_attach` 툴로 그것에 붙는다. `session_list`·`session_end` 툴을 노출한다. 컴팩션은 MCP 프로세스를 죽이지 않으므로 복귀 절차가 없다. **CLI 폴백**: 스킬은 첫 턴에 `session start`를 실행해 사용자에게 URL을 알리고, 이후 모든 호출에 `--session <키>`를 붙인다. 컴팩션으로 키를 잃으면 `session list`로 복귀한다 — 같은 프로젝트에 하나면 자동, 여럿이면 탭 제목의 키를 사용자에게 묻는다. 캔버스 세션은 사용자의 `session end`로 끝나거나, 연결이 0개인 상태(붙은 MCP 프로세스 없음, 열린 브라우저 탭 없음)가 30분 이어지면 캔버스 서버가 스스로 끝낸다(2026-10-05 그릴 확정). ([ADR-0003](../../../docs/adr/0003-one-canvas-server-per-session.md))

- 키는 서버가 발급한다. 호스트 세션 ID·PPID에 의존하지 않아 Claude·Codex 동일.
- 업스트림의 "머신당 서버 하나, 포트 3000, pid 파일" 전제를 세션 단위로 바꾼다. 빈 포트 탐색.
- 브라우저 탭 제목에 세션 키가 보인다.
- **프로젝트 루트 고정 (검수 R03, 2026-09-14 그릴 확정):** `session start`는 `--project <경로>`를 반드시 받고(2026-10-05 Q5 개정, 구 "cwd에서 찾고 `--project`로 덮어쓰기"), 그 경로에서 위로 올라가 git 루트를 찾아 캔버스 세션의 프로젝트 루트로 저장한다. git 루트가 없으면 받은 경로. `--project`가 없으면 그 인자를 안내하는 에러를 낸다. cwd는 쓰지 않는다. 출력과 `session list`에 프로젝트 루트가 나온다. 이후 모든 호출은 세션 키만으로 그 루트를 쓴다 — 근거 검사(07)·스냅샷 폴더(06)의 기준이 `process.cwd()`에서 세션의 프로젝트 루트로 바뀐다. ([ADR-0003](../../../docs/adr/0003-one-canvas-server-per-session.md)·[ADR-0005](../../../docs/adr/0005-server-checks-evidence-and-demotes.md))
- 캔버스를 쓰는 CLI 커맨드는 `--session <키>`를 반드시 받는다. 없으면 살아 있는 캔버스 세션의 목록(키, 프로젝트 루트)을 담은 에러를 낸다. 살아 있는 캔버스 세션이 0개여도 같은 에러이고 목록이 비어 있으며 `session start`를 안내한다. (2026-10-05 Q2 개정. 구 "하나일 때 그 세션으로"(2026-09-19 2차 검수 A6)는 폐기)

## 구현 시작점 (2026-10-05)

**Q1~Q6은 모두 정해졌다. 사용자에게 다시 묻지 않고 구현한다.** 만들 것의 기준은 위의 본문과 인수이고, 이유는 [ADR-0003](../../../docs/adr/0003-one-canvas-server-per-session.md)에 있다. 본문과 아래 "정할 것"의 확정 줄이 다르면 확정 줄이 맞다(본문의 CLI 폴백 문장은 `--project` 필수, `--session` 필수를 아직 적지 않았다). 아래 "결정 없이 고칠 것"에서 ~~줄 그은~~ 항목은 끝났고, 나머지는 이 구현에서 함께 고친다. 시작 전에 `CONTEXT.md`와 ADR-0003을 읽는다. 사용자에게 하는 보고는 짧게 한다(결론 한 줄, 항목당 한 줄).

구현에서 함께 고칠 스킬 문서(Q2~Q6에서 나온 것):

- `canvas-ops.md`의 "All commands run from this skill's folder" 문장을 지우고, CLI 폴백의 `session start --project <경로>`와 모든 캔버스 명령의 `--session <키>` 필수를 적는다.
- 키로 다른 캔버스 세션을 끝내는 것(`session_end`에 키)은 사용자가 말했을 때만 한다.

- 업스트림의 `start`/`stop`/`status`, `EXPRESS_SERVER_URL` 안내를 스킬 문서와 README에서 지운다.
