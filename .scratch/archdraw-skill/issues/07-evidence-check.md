# 07: 근거 검사 — `코드` 태그의 파일:줄을 그릴 때마다 서버가 확인한다

> 02 도그푸딩(구현 뒤)의 판정이 수정 사항으로 돌아온다. 검사 시점(매번 vs 저장 시)은 실사용에서 방해되면 재검토한다.

**What to build:** 에이전트가 선이나 값에 근거 태그를 붙여 그린다. `코드` 태그는 `파일:줄`을 함께 적고, 서버가 그 파일·줄이 실제로 있는지 **그릴 때마다** 확인한다. 없거나 틀리면 그 선은 점선으로 강등되고 캔버스에 "근거 없음: A→B" 텍스트가 자동으로 생긴다. `설계`·`로그` 태그는 검사 없이 기록만 한다. 근거 태그는 캔버스에 보이지 않는 요소 데이터다 — 서버와 `describe`만 읽고, 사용자는 점선과 `추론`·`근거 없음` 라벨을 본다. 의미(정말 의존성인지)는 검사하지 않는다 — 판단은 에이전트, 검증은 서버. ([ADR-0005](../../../docs/adr/0005-server-checks-evidence-and-demotes.md))

- 요소에 `evidence: {tag: code|design|log, path, line}` 칸 추가.
- 생성 경로(MCP create/batch, CLI `add`/`apply`)가 공유하는 한 곳에 검사를 넣는다. 레포 위치는 세션의 프로젝트 루트(04, 검수 R03 — 구 "서버 cwd").
- 선 표기(검수 R05)는 PRD §3 "선 표기"를 따른다. 강등·복구 시 화살촉과 통신 방식·응답 라벨을 보존한다. 에이전트가 붙인 `추론` 라벨도 유지한다.
- 강등은 하되 거부하지 않는다. archify의 거부 루프와 다른 점.
- 에이전트가 처음부터 점선(추론)으로 그린 선은 건드리지 않는다. 서버가 내린 선은 요소에 "서버 강등" 표시를 남기고, 근거가 맞아지면 서버가 실선으로 되돌리며 "근거 없음" 텍스트를 지운다.
- **생성 후 수명주기 (검수 R04, 2026-09-14 그릴 확정):**
  1. `evidence` 칸이 바뀌면 생성·수정(CLI `update`/`apply`, MCP update, 서버 PUT) 어디서든 같은 검사가 돈다.
  2. import·`snapshot restore`로 들어오는 요소도 같은 검사. 저장 뒤 코드가 바뀌어 사라진 근거는 복원 시점에 강등된다. 실선 = 지금 코드에 있다.
  3. "근거 없음: A→B" 텍스트는 원본 선 ID를 기억한다. 선이 움직이면 따라가고(라벨처럼 붙임), 선이 삭제되거나 실선 복구되면 서버가 지운다. import 복사(06) 때 ID 재매핑에 포함한다.
  4. 브라우저 왕복(사용자가 요소를 만지고 저장·재로드)에서 `evidence`·"서버 강등" 표시가 보존되는지는 기술 확인 — 깨지면 프론트 작업이 이 이슈에 추가된다.
- SKILL.md에 태그 붙이는 규칙 한 절 추가(03과 겹치면 03에서 흡수). 코드에 아직 없는 선(변경안·마이그레이션 계획·협의 중 계약)은 `설계` 태그, 실선 + 새 색 — `코드` 태그로 그리면 선마다 "근거 없음"이 쌓인다.

**Blocked by:** 01 (플러그인 골격)

**Status:** ready-for-agent

- [ ] 실재하는 `파일:줄`로 `코드` 태그 화살표를 만들면 실선 그대로다
- [ ] 없는 파일이나 범위 밖 줄이면 화살표가 점선이 되고 "근거 없음: A→B" 텍스트가 옆에 생긴다
- [ ] `설계`·`로그` 태그는 검사 없이 통과하고 `describe`에 태그가 보이며, 캔버스 스크린샷에는 태그 텍스트가 없다
- [ ] 태그 없는 요소는 업스트림과 동일하게 동작한다(하위 호환)
- [ ] 실선 화살표의 근거를 없는 줄로 `update`하면 점선 + "근거 없음"이 되고, 다시 있는 줄로 고치면 실선으로 돌아오며 텍스트가 사라진다
- [ ] 에이전트가 처음부터 점선으로 그린 화살표에 맞는 근거를 붙여도 서버가 실선으로 올리지 않는다
- [ ] 점선 화살표를 지우면 "근거 없음" 텍스트도 사라지고, 화살표를 옮기면 텍스트가 따라간다
- [ ] 근거 파일을 지운 뒤 `snapshot restore`·`import`하면 그 선만 점선이 되고 나머지는 그대로다
- [ ] 브라우저에서 화살표를 끌어 옮긴 뒤 `describe`에 `evidence`와 "서버 강등" 표시가 남아 있다
- [ ] 기존 `npm test` 통과

- [ ] 확인된 동기 호출·비동기 이벤트·응답의 코드 근거를 틀리게 바꾸면 점선 + `근거 없음`이 되며, 화살촉과 `[동기]`·`[비동기]`·`응답: 결과` 라벨은 각각 유지된다. 근거를 복구하면 같은 통신 표기의 실선으로 돌아온다
- [ ] 처음부터 `추론` 라벨을 붙인 점선은 유효한 코드 근거 검사 뒤에도 점선 + `추론`으로 남아, 서버가 강등한 점선 + `근거 없음`과 구분된다
