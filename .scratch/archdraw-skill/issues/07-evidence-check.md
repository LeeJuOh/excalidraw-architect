# 07: 근거 검사 — `코드` 태그의 파일:줄을 그릴 때마다 서버가 확인한다

> 02 도그푸딩(구현 뒤)의 판정이 수정 사항으로 돌아온다. 검사 시점(매번 vs 저장 시)은 실사용에서 방해되면 재검토한다.

**What to build:** 에이전트가 선이나 값에 근거 태그를 붙여 그린다. `코드` 태그는 `파일:줄`을 함께 적고, 서버가 그 파일·줄이 실제로 있는지 **그릴 때마다** 확인한다. 없거나 틀리면 그 선은 점선으로 강등되고 캔버스에 "근거 없음: A→B" 텍스트가 자동으로 생긴다. `설계`·`로그` 태그는 검사 없이 기록만 한다. 근거 태그는 캔버스에 보이지 않는 요소 데이터다 — 서버와 `describe`만 읽고, 사용자는 점선과 "근거 없음" 텍스트만 본다. 의미(정말 의존성인지)는 검사하지 않는다 — 판단은 에이전트, 검증은 서버. ([ADR-0005](../../../docs/adr/0005-server-checks-evidence-and-demotes.md))

- 요소에 `evidence: {tag: code|design|log, path, line}` 칸 추가.
- 생성 경로(MCP create/batch, CLI `add`/`apply`)가 공유하는 한 곳에 검사를 넣는다. 레포 위치는 서버 cwd.
- 강등은 하되 거부하지 않는다. archify의 거부 루프와 다른 점.
- 에이전트가 처음부터 점선(추론)으로 그린 선은 건드리지 않는다. 서버는 내리기만 하고 올리지 않는다.
- SKILL.md에 태그 붙이는 규칙 한 절 추가(03과 겹치면 03에서 흡수). 코드에 아직 없는 선(변경안·마이그레이션 계획·협의 중 계약)은 `설계` 태그, 실선 + 새 색 — `코드` 태그로 그리면 선마다 "근거 없음"이 쌓인다.

**Blocked by:** 01 (플러그인 골격)

**Status:** ready-for-agent

- [ ] 실재하는 `파일:줄`로 `코드` 태그 화살표를 만들면 실선 그대로다
- [ ] 없는 파일이나 범위 밖 줄이면 화살표가 점선이 되고 "근거 없음: A→B" 텍스트가 옆에 생긴다
- [ ] `설계`·`로그` 태그는 검사 없이 통과하고 `describe`에 태그가 보이며, 캔버스 스크린샷에는 태그 텍스트가 없다
- [ ] 태그 없는 요소는 업스트림과 동일하게 동작한다(하위 호환)
- [ ] 기존 `npm test` 통과
