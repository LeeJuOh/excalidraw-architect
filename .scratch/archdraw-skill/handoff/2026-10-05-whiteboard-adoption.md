### 측정한 사실

- **`roots/list` 응답 (probe MCP 서버를 `claude -p`와 `codex exec`에 붙였다):** Claude Code 2.1.289는 `roots` 기능을 선언하고 세션을 시작한 폴더 하나를 답했다(git 루트가 아니다. `docs/`에서 시작하면 `docs/`). Codex 0.160.0은 `roots` 기능을 선언하지 않고 빈 목록을 답했으며, MCP 프로세스에 `PWD`·`CODEX_*` env를 하나도 넘기지 않았다.
- **Claude Code의 `/clear`는 MCP 프로세스를 다시 시작하지 않는다:** 이 세션의 `ps`에서, 우리 MCP 프로세스는 `/clear`보다 27분 먼저 시작했고 `/clear` 뒤에도 같은 pid였다.
